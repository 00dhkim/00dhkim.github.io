Google 연결 설정

처음 한 번, 개인 Google Cloud 프로젝트의 웹 애플리케이션 OAuth 클라이언트 ID를 입력하세요. 클라이언트 시크릿은 필요하지 않습니다.

  1. Google Cloud에서 개인 프로젝트를 만들고 Google Calendar API를 활성화합니다.
  2. Google Auth Platform에서 대상을 외부 / 테스트로 설정하고, 테스트 사용자에 개인 Google 이메일을 추가합니다.
  3. 클라이언트 → 웹 애플리케이션을 만들고 승인된 JavaScript 원본에 를 추가합니다.
  4. 발급된 클라이언트 ID를 위에 저장한 뒤 Google 캘린더 연결을 누릅니다.

클라이언트 ID·선택한 캘린더·기간은 이 브라우저에 자동 저장합니다. 로그인은 현재 탭에서 새로고침해도 만료 전까지 유지합니다. 인증이 만료되거나 탭을 닫으면 다시 연결해 주세요. 운동 기록과 인증 토큰은 GitHub에 업로드하지 않습니다.
